# DURESBOT DRAGON

Tema konsep Pterodactyl dengan latar hitam-hijau gelap, panel gelap, tombol hijau neon, dan watermark DURESBOT.

## Isi
- `theme.css` — stylesheet tema.
- `theme.json` — metadata untuk katalog.
- `README.md` — petunjuk dan batas kompatibilitas.

## Penting
Paket ini adalah draft stylesheet, bukan installer panel siap produksi. Pterodactyl tidak otomatis memuat CSS dari folder ini. Diperlukan integrasi/theme loader yang cocok dengan versi panel yang dipakai. Jangan menimpa file inti panel atau menjalankan installer acak. Uji pada salinan/staging dan buat backup terlebih dahulu.

## Tambahkan ke katalog GitHub
Buat folder `DURESBOT-DRAGON` di root repository `tema-pterodactly`, lalu unggah ketiga file ini ke dalam folder tersebut. Endpoint katalog root GitHub yang sudah dikonfigurasi pada bot akan dapat melihat folder tersebut.
